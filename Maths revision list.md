# Maths revision list

Based on the June 2019 Paper 1 you shared. The marking was approximate, so this list includes both topics where your answers lost marks and topics you left blank or marked “idk”.

## Work on these first

- **Integration and areas between curves** (Q8): set up definite integrals, use signed area correctly, evaluate limits, and form equations from equal areas.
- **Quadratics: completing the square, transformations and range** (Q5): write a quadratic in completed-square form, sketch its key features, describe translations, and find the range of a transformed reciprocal function.
- **Trigonometric equations** (Q6): rearrange equations involving sine, cosine and tangent, find every solution in a stated interval, and use identities carefully.
- **Geometric sequences and series** (Q11): identify the first term and common ratio, use the finite and infinite sum formulas, and model quantities that change by a percentage each step.
- **Exponential models and depreciation** (Q7): build a model from starting value and percentage change, evaluate it, and discuss how well it fits later data.
- **Logarithm laws and restrictions** (Q9): combine and rearrange logarithms, solve for a variable, and state restrictions that keep logarithm arguments valid.
- **Proof with integers and remainders** (Q10): use even/odd forms such as n = 2k or n = 2k + 1, and explain divisibility using remainders correctly.
- **Rational functions and partial fractions** (Q13): use asymptotes and given points to find constants, decompose into partial fractions, and integrate logarithmic terms.
