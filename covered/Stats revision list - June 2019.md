## Topics to revise

1. **Stratified sampling — Question 1(a)**
   - You got the proportional numbers right: 24 students from Year 12 and 16 from Year 13.
   - The description also needed a sampling frame for each year group (for example, numbered lists) and random selection from each list.
   - Revise how to describe a complete stratified random sample: split into groups, make a list for each group, then randomly select the required number from each.

2. **Using a regression gradient — Question 1(b)**
   - The gradient is 5.60 marks per hour. For an extra 0.5 hours, the predicted average increase is `5.60 × 0.5 = 2.8 marks`, not 5.6.
   - Revise scaling a rate or gradient when the input changes by only part of one unit.

3. **Binomial probabilities and tail notation — Question 3(b)**
   - For “at least 7”, the complement method was right: `P(X ≥ 7) = 1 − P(X ≤ 6)`. The probability calculation was wrong; the answer is about **0.322**.
   - For `P(4 ≤ X < 8)`, subtract the lower tail from the upper cumulative probability: `P(X ≤ 7) − P(X ≤ 3)`, giving about **0.658**. Your subtraction used `P(X ≥ 4) − P(X ≤ 7)`, which does not represent the required interval.
   - Revise binomial cumulative probabilities, inclusive/exclusive endpoints, and converting “at least” or an interval into calculator commands.

4. **Grouped data: midpoint assumptions — Question 4(d)(i)**
   - The required assumption is that values are spread evenly within each class, so the class midpoint can represent that class. “Evenly distributed about the mean” does not state this assumption.
   - Revise when grouped-data estimates are valid and how to explain the limitation using the rainfall data (many values in the first class are zero or close to zero).

5. **One-tailed hypothesis tests — Question 5(a)**
   - The alternative hypothesis should be `H₁: p > 0.15`, not `p ≥ 0.15`.
   - The test probability should use the upper tail `P(X ≥ 8)`, not the single outcome `P(X = 8)`. You identified the tail-probability error in your working; practise writing the corrected hypothesis and test probability explicitly.
